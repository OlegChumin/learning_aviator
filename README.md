# Learning Aviator

Проект для изучения и практики работы с DSL-движком [Aviator](https://github.com/killme2008/aviator).

Автор: **Олег Чумин**

---

## 🚀 Описание

Данный проект является учебным и служит базой для:

- Знакомства с [Aviator Expression](https://github.com/killme2008/aviator)
- Интеграции его с Java-кодом
- Создания пользовательских функций и регистрации их в DSL
- Изучения взаимодействия с Spring Boot + Thymeleaf

---

## ✅ Что работает "из коробки" без регистрации:

- `now()` — возвращает `long` (timestamp).
- Арифметика: `+`, `-`, `*`, `/`, `%`, скобки, приоритеты.
- Логика: `&&`, `||`, `==`, `!=`, `>`, `<`, `>=`, `<=`, тернарный `? :`.
- Строковые функции: `string.contains`, `string.startsWith`, `string.endsWith`, `string.length`, `string.toUpperCase`, `string.toLowerCase`.

---

## 📦 Состав

- Java 21
- Spring Boot 3.5.3
- Aviator 5.4.3
- Thymeleaf (шаблонизатор)

## 🖥️ Как запустить

1. Клонируй репозиторий:

```bash
git clone https://github.com/<твой-профиль>/learning_aviator.git
cd learning_aviator
```

2. Собери и запусти приложение:

```bash
./gradlew bootRun
```

3. Открой в браузере: 👉 [http://localhost:8098](http://localhost:8098)

### Запуск через Docker

Сборка и запуск контейнера:

```bash
docker compose up -d --build
```

После запуска приложение доступно по адресу: 👉 [http://localhost:8098](http://localhost:8098)

На Windows можно запустить приложение и автоматически открыть браузер одной командой:

```powershell
.\run-docker.ps1
```

Остановка контейнера:

```bash
docker compose down
```

## 🔐 Что сделано по безопасности

- Добавлено серверное ограничение длины выражения: максимум `500` символов.
- Слишком длинные выражения отклоняются до вызова `AviatorEvaluator`.
- История вычислений ограничена последними `100` уникальными записями.
- Доступ к общей истории синхронизирован, так как контроллер является singleton bean.
- `HomeController` сделан `final`, чтобы поведение контроллера не расширялось наследованием.
- Версия приложения передается через constructor injection и хранится в `final` поле.
- Вывод пользовательских значений в шаблонах выполняется через `th:text`, поэтому HTML экранируется Thymeleaf.
- Для Docker добавлен `.dockerignore`, чтобы в build context не попадали `.git`, `.gradle`, `.idea`, `build` и другие локальные файлы.
